# 2. 4つの胃と反芻

## この章でわかること

- 4つの胃のはたらき
- 反芻とは何か、なぜ大事か
- 第一胃の微生物と、エサが乳になるまで
- ルーメンアシドーシス

## 4つの胃

![牛の4つの胃とエサの流れ](images/stomach.svg)

| 胃 | 英語 | 焼肉での名前 | はたらき |
| --- | --- | --- | --- |
| 第一胃 | rumen（ルーメン） | ミノ | いちばん大きい（大人で 150〜200 L）。微生物がエサを発酵させる「発酵タンク」 |
| 第二胃 | reticulum | ハチノス | 第一胃とつながっていて、中身をかき混ぜる。食べたものを口に戻す（反芻）入口。飲み込んだ金属がたまりやすい |
| 第三胃 | omasum | センマイ | 薄いひだがたくさんある。水分を吸い、細かくなったものだけを先へ送る |
| 第四胃 | abomasum | ギアラ | 人の胃と同じ。胃酸と消化酵素で消化する |

- 4つの胃は、お腹の左側の大部分を占めます。第一胃が全体の 8割ほどです
- 生まれたばかりの子牛は、第四胃がいちばん大きく、第一胃はまだ小さいです。ミルクは食道溝（しょくどうこう）という通り道を通り、第一胃を通らずに第四胃に入ります。草や固形のエサを食べ始めると、第一胃が育ちます（4章）

## 反芻

- **反芻**（はんすう, rumination）: 一度飲み込んだエサを口に戻して、もう一度かむこと
- 1日に **7〜10時間**（400〜600分）も反芻します。多くは横になって休んでいるときです
- 口に戻した1つのかたまりを、40〜70回ほどかんでから、また飲み込みます
- かむと唾液がたくさん出ます。1日に 100〜180 L にもなります
- 唾液には重曹（炭酸水素ナトリウム）のような成分が入っていて、第一胃が酸っぱくなりすぎないようにします（緩衝作用）

### 反芻が大事なわけ

- 草を細かくして、微生物が分解しやすくする
- 唾液で、第一胃の pH を保つ
- **反芻が減るのは、体の調子が悪いサイン**です。病気・お産・発情・暑さ・ストレスで減ります。だから首輪などのセンサーで反芻の時間を測ります（12章）
- 草（繊維）の少ないエサでは、反芻が減る → 唾液が減る → 第一胃が酸性に傾く（下の「ルーメンアシドーシス」）

## 第一胃の微生物

- 第一胃には、細菌・原虫・カビ（真菌）などの微生物がすんでいます。中身 1 mL に、細菌が 100億個以上います
- 牛は自分では草の繊維（セルロース）を消化できません。**微生物が分解して発酵させ**、牛はその産物をもらって生きています
- 発酵でできる**揮発性脂肪酸**（VFA）が、牛のエネルギーの 6〜7割をまかないます

| VFA | 英語 | 多くなるエサ | 体の中で |
| --- | --- | --- | --- |
| 酢酸 | acetic acid | 草（繊維） | 乳脂肪のもとになる |
| プロピオン酸 | propionic acid | 穀物（デンプン） | 肝臓でブドウ糖になる → 乳糖 → 乳の量 |
| 酪酸 | butyric acid | 糖・デンプン | 第一胃の壁の栄養になる |

- 微生物そのものも、第四胃と小腸で消化されて、牛のたんぱく質になります（微生物たんぱく質）
- 発酵でメタンガスもでき、げっぷで出ます。1頭で 1日に数百 L になり、温室効果ガスとして、減らす研究が進んでいます（ニュースによく出ます）

## エサが乳になるまで

1. 口でかむ（草をちぎって飲み込む）
2. 第一胃・第二胃で、微生物が発酵させる（VFA と微生物ができる）
3. 反芻で、口に戻してかみ直す（何度もくり返す）
4. 細かくなったものが第三胃 → 第四胃 → 小腸へ進み、消化・吸収される
5. VFA は第一胃の壁から、そのほかは小腸から吸収され、血液に入る
6. 血液が乳房に運ばれ、乳になる（8章）

## ルーメンアシドーシス

- **ルーメンアシドーシス**（rumen acidosis）: 第一胃が酸性になりすぎる病気
- 穀物（濃厚飼料）を急に・たくさん食べる → デンプンが速く発酵して酸がたくさんできる → 第一胃の pH が下がる
- 正常な pH は 6〜7 です。5.8 を下回る時間が長く続くのが**亜急性ルーメンアシドーシス**（SARA）、5.0 を下回ると急性で、命にかかわります

![第一胃の pH の1日の変化（エサの与え方によるちがい）](images/rumen-ph.svg)

| サイン | 理由 |
| --- | --- |
| 食べむらがある、反芻が減る | 第一胃の調子が悪い |
| 便がやわらかい、泡や消化されていない穀物が混じる | 第一胃で消化しきれていない |
| 乳脂肪率が下がる | 酢酸が減る |
| 蹄の病気が増える | 酸や毒素が体をめぐり、蹄を傷める（11章） |

防ぐには、草（繊維）を十分に与える、濃厚飼料を一度にたくさん与えない（何回かに分ける・TMR）、エサを急に変えない、ことです（5章）。

## まとめ

- 牛の胃は4つ。第一胃（ルーメン）は微生物の発酵タンク
- 反芻は 1日 7〜10時間。唾液が第一胃を守る。反芻が減るのは不調のサイン
- 微生物が草を発酵させてできる VFA が、牛のエネルギーと乳のもと
- 穀物が多すぎるとルーメンアシドーシス。草とのバランスが大事
