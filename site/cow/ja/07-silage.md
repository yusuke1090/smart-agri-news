# 7. サイレージ

## この章でわかること

- サイレージとは

- 作り方
- 失敗と、よいサイレージの見分け方

## サイレージとは

- **サイレージ**（silage）: 刈った草やトウモロコシを、空気を抜いて密封し、**乳酸菌で発酵**させて保存したエサです。「草の漬物」と考えるとわかりやすいです
- 乾草とちがって晴れの日が何日も要らないので、雨の多い日本でも作りやすく、栄養を長く保てます
- 1年分をまとめて作り、毎日少しずつ取り出して与えます
- サイレージを作る入れ物や場所を**サイロ**（silo）といいます

## 発酵のしくみ

![サイレージの作り方と発酵](images/silage.svg)

1. 詰めて密封した直後は、草がまだ呼吸していて、残った酸素を使い切ります（数時間〜1日）
2. 酸素がなくなると、**乳酸菌**が増え、草の糖分から乳酸を作ります
3. 乳酸で pH が **4 前後**まで下がると、腐らせる菌が増えられなくなり、安定します（3〜6週間）
4. 空気が入らない限り、何か月も保存できます

うまく作るポイントは、次の3つです。

- **空気を抜く**: 細かく切る、よく踏み固める、すぐに密封する
- **糖分が十分にある**: 乳酸菌のエサ。マメ科の草は糖分が少なく、難しい
- **水分がちょうどよい**: 多すぎても少なすぎても失敗する

発酵を助けるために、乳酸菌の添加剤を使うこともあります。

## サイレージの種類

| 種類 | 英語 | 説明 |
| --- | --- | --- |
| コーンサイレージ | corn silage（whole-crop） | トウモロコシの実・茎・葉を丸ごと細かく切って作る。実のデンプンが多く、エネルギーが高い。実が黄色く固まりかけたころ（黄熟期）に刈る |
| グラスサイレージ | grass silage | 牧草で作る。少し乾かして（予乾）水分を下げてから詰める |
| ラップサイレージ | wrapped bale silage（baleage） | 牧草を丸く固め、フィルムで何重にも巻いて作る。畑に並ぶ白や黒の大きな丸いもの |
| 稲WCS（稲発酵粗飼料） | whole-crop rice silage | 稲を実ごと刈って作る。田んぼを使って作れる |
| ヘイレージ | haylage | 水分を低め（40〜50%）にした牧草のサイレージ |

## サイロの種類

| サイロ | 英語 | 説明 |
| --- | --- | --- |
| バンカーサイロ | bunker silo | 3方をコンクリートの壁で囲んだ場所に詰め、重機で踏み固め、シートで覆う。大きな牧場に多い |
| スタックサイロ | drive-over pile | 壁を作らず地面に積み上げ、シートで覆う |
| タワーサイロ | tower silo | 昔ながらの塔の形。牧場の絵によく描かれる |
| バッグサイロ | silo bag | 長い袋に詰める |
| ロールベール | wrapped bale | 1つずつフィルムで巻く（ラップサイレージ） |

## 作り方（コーンサイレージの例）

1. 黄熟期のトウモロコシを、ハーベスター（収穫機）で刈りながら 1〜2 cm に細かく切る
2. すぐにサイロに運び、薄く広げては重機で何度も踏み固める（空気を抜く）
3. その日のうちにシートで覆い、タイヤなどの重しを乗せて密封する
4. 少なくとも 3週間、できれば 1か月以上置いて発酵させてから使い始める

水分の目安は、コーンサイレージで 65〜70%、グラスサイレージで 60〜70% です。

## 失敗したサイレージ

| 失敗 | 原因 | どうなるか |
| --- | --- | --- |
| 酪酸発酵 | 水分が多すぎる、糖が少ない、土が混じる | 酪酸菌が増え、腐ったようなひどいにおいになる。牛が食べず、ケトーシスの原因にもなる |
| カビ | 空気が入る（踏み固めが足りない・シートの穴） | 栄養が減る。カビ毒（マイコトキシン）で牛の健康を損なう |
| 二次発酵 | 開けたあと、空気にふれて酵母やカビが増える | 熱を持ち、においが変わり、牛が食べなくなる |

- **二次発酵**（好気的変敗）を防ぐには、開けた面（切り口）を小さく平らにし、毎日ある程度の厚さ（目安 15〜30 cm。暑い時期ほど多く）を取り出します
- シートの穴は、見つけたらすぐにふさぎます（カラスやネズミが開けることもあります）

## よいサイレージの見分け方

| 見るところ | よい | よくない |
| --- | --- | --- |
| におい | 甘酸っぱい（ヨーグルトや漬物のよう） | ツンとする酢のにおい、腐ったにおい（酪酸）、カビ臭い |
| 色 | 黄緑〜黄色っぽい茶色 | 黒っぽい、白や青のカビ |
| 手ざわり | しっとり | ベタベタ（水分が多すぎ）、熱い（二次発酵） |
| pH | 4.2 以下（コーンは 3.8〜4.0） | 高い |

## まとめ

- サイレージは、空気を抜いて乳酸菌で発酵させた「草の漬物」。pH 4 前後で安定する
- コーンサイレージはエネルギーが高い。ラップサイレージは畑に並ぶ白い丸いもの
- 空気を抜く・糖分・水分がポイント。失敗すると酪酸発酵やカビ
- 開けたあとの二次発酵を防ぐため、毎日切り口から取り出す
