# 6. 乾草と牧草（チモシー・アルファルファ）

## この章でわかること

- 牧草の2つのグループ（イネ科とマメ科）
- チモシーとアルファルファの特徴とちがい
- そのほかの粗飼料
- 乾草の作り方と、刈る時期
- よい乾草の見分け方

## 牧草の2つのグループ

| グループ | 英語 | 特徴 | 例 |
| --- | --- | --- | --- |
| イネ科 | grasses | 繊維が多く、たんぱく質は少なめ。カルシウムも少なめ | チモシー、オーチャードグラス、イタリアンライグラス |
| マメ科 | legumes | たんぱく質とカルシウムが多い。根に根粒菌がすみ、空気中の窒素を使えるので、肥料が少なくてすむ | アルファルファ、クローバー |

## チモシー

- **チモシー**（timothy）: イネ科の牧草。和名はオオアワガエリ
- 何年も育つ多年草で、寒さに強く、北海道でたくさん作られています。アメリカやカナダからも輸入しています
- 穂は細長い円柱の形です
- 繊維が多めで、たんぱく質は少なめ（粗たんぱく質 8〜12% ほど）。カルシウムが少ないです
- 牛がよく食べます（嗜好性がよい）。反芻を増やすのに向いています
- 向いている牛: **乾乳牛・育成牛・子牛**。乾乳牛では、カルシウムが少ないことがお産のあとの乳熱を防ぐのに役立ちます（11章）
- ただし、ふん尿を肥料にたくさん入れた畑の草は、カリウムが多くなることがあり、乾乳牛では注意します
- ウサギや馬のエサとしても有名です

## アルファルファ

- **アルファルファ**（alfalfa）: マメ科の牧草。イギリスなどでは lucerne（ルーサン）とも呼びます。和名はムラサキウマゴヤシ
- 紫の花が咲く多年草で、根が地中深く（数 m）まで伸びます。栄養が多いので「牧草の女王」と呼ばれます
- **たんぱく質**（粗たんぱく質 17〜22%）と**カルシウム**（1.2〜1.5%）が多く、消化がよいです
- 向いている牛: **乳をたくさん出している牛**。濃厚飼料のたんぱく質を減らせます
- 日本では、主にアメリカから輸入しています。乾草のほか、固めた角形の**ヘイキューブ**や、ペレットもあります

### アルファルファで気をつけること

- **乾乳牛に多く与えない**: カルシウムとカリウムが多すぎると、お産のときに骨からカルシウムを出す体の仕組みが働きにくくなり、乳熱（低カルシウム血症）が起きやすくなります（11章）
- **生の草をたくさん食べると鼓脹症**: 第一胃のガスが泡になって出せなくなり、お腹がふくれます（11章）
- **葉に栄養が多い**: 乾かすときに葉が落ちやすいので、ていねいに扱います。葉の多いものほど上等です

## チモシーとアルファルファの比較

![チモシーとアルファルファの、たんぱく質とカルシウム](images/timothy-alfalfa.svg)

| | チモシー | アルファルファ |
| --- | --- | --- |
| 英語 | timothy | alfalfa（lucerne） |
| グループ | イネ科 | マメ科 |
| たんぱく質 | 少なめ（8〜12%） | 多い（17〜22%） |
| カルシウム | 少ない（0.3〜0.5%） | 多い（1.2〜1.5%） |
| 繊維 | 多い | 少なめで、消化がよい |
| 向いている牛 | 乾乳牛・育成牛・子牛 | 乳を出している牛 |
| 注意 | 遅く刈ると固くなり、栄養が下がる | 乾乳牛の乳熱、生草の鼓脹症 |

## そのほかの粗飼料

| 名前 | 英語 | 特徴 |
| --- | --- | --- |
| オーチャードグラス | orchardgrass | イネ科。チモシーより暑さに強い。本州の牧草地に多い |
| イタリアンライグラス | Italian ryegrass | イネ科。育つのが速い。秋にまいて春に刈ることが多い |
| スーダングラス | sudangrass | イネ科。夏に育つ |
| クローバー | clover | マメ科。イネ科の牧草と一緒にまくことが多い |
| 稲わら | rice straw | 栄養は少ないが、繊維を足すのに使う。乾乳牛や育成牛に |
| トウモロコシ | corn（maize） | 実ごと刈ってサイレージにすることが多い（7章） |

## 乾草の作り方

1. **刈る**（モア）
2. **広げて干し、ひっくり返す**（テッダー）。晴れの日が 3〜4日ほど必要
3. **集めて列にする**（レーキ）
4. **固める**（ベーラー）。四角いベールや、丸いロールベールにする

- 水分を **15% 以下**まで下げます。湿ったまま積むと、カビたり、熱を持って燃え出したりすることもあります
- 雨に当たると、栄養が流れ、カビやすくなります。雨の多い日本では乾草作りが難しいので、少し乾かしてサイレージにすること（ラップサイレージ, 7章）も多いです

## 刈る時期と栄養

![刈る時期と、とれる量・栄養](images/cutting-time.svg)

| 刈る時期 | 栄養 | 量 |
| --- | --- | --- |
| 早い（若い草） | 葉が多く、たんぱく質が多く、消化がよい | 少ない |
| 遅い（穂や花が出たあと） | 茎が固く、繊維が多く、消化が悪い | 多い |

- イネ科は穂が出るころ（出穂期）、アルファルファは花が咲き始めるころが、量と質のバランスがよいとされます
- 1年に何回か刈ります。1回目を 1番草、2回目を 2番草と呼びます

## よい乾草の見分け方

| 見るところ | よい | よくない |
| --- | --- | --- |
| 色 | 緑色 | 茶色・黒っぽい（雨や日光に当たりすぎ） |
| におい | 草の甘いにおい | カビ臭い・ほこりっぽい |
| 葉 | 葉が多い | 茎ばかり・葉が落ちている |
| 手ざわり | やわらかい | 固い・チクチクする |
| カビ | ない | 白や黒の粉。カビ毒（マイコトキシン）は牛にも人にも悪い |

見た目だけでなく、成分を分析（飼料分析）して、エサの設計に使います。

## まとめ

- 牧草には、繊維の多い**イネ科**（チモシーなど）と、たんぱく質とカルシウムの多い**マメ科**（アルファルファなど）がある
- **チモシー**は乾乳牛・育成牛・子牛向き。**アルファルファ**は乳を出している牛向き
- アルファルファは、乾乳牛の乳熱と、生草の鼓脹症に注意
- 乾草は水分 15% 以下まで乾かす。早く刈るほど栄養が高い
