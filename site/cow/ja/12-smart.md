# 12. 牛の暮らしとスマート酪農

## この章でわかること

- 牛の一日の過ごし方
- 牛舎の種類
- 酪農家の一日の仕事
- センサーとロボットでわかること・できること
- センサーを使うときに大事なこと

## 牛の一日

| 行動 | 1日の時間の目安 |
| --- | --- |
| 横になって休む | 10〜14時間 |
| 食べる | 3〜5時間（1日 9〜14回に分けて） |
| 反芻する | 7〜10時間（多くは横になりながら） |
| 水を飲む | 30分ほど（1日 80〜150 L） |
| 搾乳・移動など | 2〜3時間 |

- 「よく食べ、よく休み、よく反芻する」牛が健康で、乳もよく出します。牛が快適に過ごせることを**カウコンフォート**（cow comfort）といいます
- 立っている時間が長いと、蹄を痛め、乳房に流れる血液も減ります

## 牛舎の種類

| 種類 | 英語 | 説明 |
| --- | --- | --- |
| つなぎ飼い | tie-stall | 1頭ずつ決まった場所につなぐ。1頭ずつ世話がしやすい。搾乳は、牛のいる場所でパイプラインミルカーを使う。日本の中小規模の牧場に多い |
| フリーストール | free-stall | 牛は自由に歩き回り、寝るときは1頭分ずつ区切られた寝床（ストール）に入る。搾乳は、ミルキングパーラー（搾乳室）か搾乳ロボットで。大きな牧場に多い |
| フリーバーン | free-barn（bedded pack） | 区切りのない広い寝床に敷料を厚く敷き、自由に過ごす |
| 放牧 | grazing（pasture） | 牧草地で草を食べて過ごす。エサ代が少なく、牛も運動できる |

## 酪農家の一日

| 時刻（例） | 仕事 |
| --- | --- |
| 5:00 | 朝の搾乳、エサやり、牛の様子を見る |
| 8:00 | 牛舎の掃除（ふん出し・敷料）、子牛の哺乳 |
| 10:00 | 発情の確認と授精、獣医師の診療、削蹄 |
| 13:00 | 畑仕事（牧草・トウモロコシ）、事務、休けい |
| 16:00 | 夕方の搾乳、エサやり、掃除 |
| 19:00 | 片付け、見回り |

- 牛の世話に休みの日はありません。お産は夜中のことも多いです
- 酪農ヘルパー（代わりに搾乳などをする人）、コントラクター（畑仕事の請負）、TMR センターなど、地域で仕事を分ける仕組みもあります
- 人手が足りないことが、スマート酪農が広がる大きな理由です

## センサーとロボット

| 技術 | 英語 | 何を測る・何をする | わかること |
| --- | --- | --- | --- |
| 首輪・足・耳の活動量計 | activity monitor（collar, pedometer, ear tag） | 加速度で、歩数・動き・頭の動きを測る | 発情（活動量が 2〜4倍）、反芻・食べる時間、病気 |
| 反芻センサー | rumination sensor | あごの動きや、かむ音 | 反芻時間が減る → 病気・お産・暑さ |
| 胃のセンサー（ボーラス） | rumen bolus | 飲み込ませて、第二胃の中で温度や動きを測る | 熱、水を飲んだ回数、お産が近いこと |
| 体温・尾のセンサー | vaginal / tail sensor | 体温や、尾の上げ方 | お産が近いこと（体温が下がる、尾をよく上げる） |
| 搾乳ロボット・ミルクメーター | milking robot（AMS）, milk meter | 乳量、電気伝導度、乳の色、体細胞 | 乳房炎、血乳、乳量の変化 |
| カメラと AI | camera + AI | 体の形、歩き方、顔 | ボディコンディションスコア（BCS）、跛行、牛の見分け |
| 通過式体重計 | walk-over scale | 通るときに体重を測る | 成長、やせた・太った |
| 環境センサー | climate sensor | 温度・湿度から THI を出す | 暑熱ストレス。送風機やミストを自動で動かす |
| 給餌・エサ寄せロボット | feeding robot, feed pusher | エサを配る、押し寄せる | 食べる量を増やし、人の手間を減らす |
| 哺乳ロボット | automatic calf feeder | 子牛ごとにミルクの量を決めて飲ませる | 飲んだ量・飲む速さ → 子牛の病気 |

### センサーで大事なこと

- 1回の数字より、**その牛のふだんとの差**を見ます（例: 反芻の時間が、ふだんより 2割減った）
- お知らせ（アラート）は診断ではありません。**人が牛を見て確かめる**きっかけです
- 牛ごとのデータは、耳標の**個体識別番号**（10けた）と結びつけて記録します
- 何年もデータを集めると、牧場全体の成績（繁殖・乳房炎・エサ）や、病気になりやすい牛も見えてきます
- スマート農業News の「酪農・畜産」「IoT・センサー」のニュースは、この章の技術の話が多いです

## まとめ

- 牛は 1日に 10〜14時間休み、7〜10時間反芻する。よく休める牛ほど乳が出る
- 牛舎には、つなぎ飼い・フリーストール・フリーバーン・放牧がある
- 酪農は休みがなく人手が足りない。だからセンサーとロボットが広がっている
- 活動量で発情、反芻で病気、電気伝導度で乳房炎、体温でお産、THI で暑さがわかる
- アラートは診断ではない。ふだんとの差を見て、人が確かめる
