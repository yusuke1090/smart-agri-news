# 1. 乳牛とは

## この章でわかること

- 乳牛と肉牛のちがい
- 乳牛の品種
- からだの大きさや乳の量の目安
- 乳牛の一生
- 牛はどんな動物か

## 乳牛と肉牛

| 種類 | 英語 | 目的 | 日本の主な品種 |
| --- | --- | --- | --- |
| 乳牛（乳用種） | dairy cattle | 乳をとる | ホルスタイン、ジャージー |
| 肉牛（肉用種） | beef cattle | 肉をとる | 黒毛和種（和牛）など |
| 交雑種（F1） | crossbred | 肉をとる | ホルスタインの母 × 黒毛和種の父 |

- 乳を出すのはメスだけです。乳牛から生まれたオスは、肉用に育てられます
- 乳牛に和牛の精液を使い、値段の高い交雑種（F1）の子牛を産ませることもよくあります

## 乳牛の品種

| 品種 | 英語 | 特徴 |
| --- | --- | --- |
| ホルスタイン | Holstein（Holstein-Friesian） | 白と黒のまだら。乳の量がいちばん多い。日本の乳牛のほとんどがこの品種 |
| ジャージー | Jersey | 茶色で小さい（体重 400〜450 kg）。乳の量は少ないが、乳脂肪が多く濃い（5% ほど）。暑さに少し強い |
| ブラウンスイス | Brown Swiss | 灰色がかった茶色で大きい。丈夫で長生き。チーズに向く乳 |
| ガーンジー | Guernsey | 薄い茶色と白。乳が少し黄色っぽい |

この教科書の数字は、ホルスタインのものです。

## 数字で見るホルスタイン

| 項目 | 目安 |
| --- | --- |
| 体重（大人のメス） | 600〜700 kg |
| 体高（肩の高さ） | 約 150 cm |
| 生まれたときの体重 | 40〜45 kg |
| 体温 | 38.0〜39.0 ℃（39.5 ℃ を超えたら熱がある） |
| 1日の乳の量 | 平均 25〜35 kg。多い時期は 40〜50 kg を超える牛もいる |
| 1年の乳の量 | 8,000〜10,000 kg ほど |
| 1日に食べる量 | 乾物（水分を除いた重さ）で 20〜25 kg。水分を含めると 40〜60 kg |
| 1日に飲む水 | 80〜150 L（暑い日や乳の多い牛はもっと） |
| 寿命 | 自然には 20年ほど生きられるが、乳牛は 5〜6歳で牧場を離れることが多い |

乳の量は、1回のお産から 305日間でまとめて数えることが多いです（305日乳量）。

## 乳牛の一生

| 時期 | 年齢の目安 | すること |
| --- | --- | --- |
| 哺育期の子牛 | 0〜2・3か月 | 初乳を飲む。ミルクと子牛用のエサで育つ（4章） |
| 育成牛 | 3か月〜初めてのお産 | からだを大きくする。13〜15か月で初めて授精する（3章） |
| 初産 | 22〜24か月 | 初めて子牛を産み、乳を出し始める |
| 経産牛 | 2歳〜 | 「お産 → 乳を出す（約305日）→ 乾乳（約60日）→ お産」をくり返す |
| 牧場を離れる | 5〜6歳ごろ | 乳が減った、子ができにくい、病気、脚が悪い、などの理由で。多くは肉になる |

- **乳を出すのは、子牛を産んだあとだけ**です。だから乳牛は、毎年のようにお産をします（3章の「1年1産」）
- 乳を止めて休ませる期間を、乾乳期（かんにゅうき, dry period）といいます
- 生まれたメスの子牛は、次の乳牛として育てます。メスが生まれやすい精液（性選別精液）を使うこともあります

## 牛はどんな動物か

- 草を食べる**反芻動物**（ruminant）です。4つの胃を持ち、食べた草を口に戻してかみ直します（2章）
- **群れ**で暮らします。群れの中には順位があり、強い牛が先にエサを食べます
- **暑さに弱く、寒さに強い**です。快適なのは 5〜20 ℃ くらいで、暑いと食べる量と乳の量が減ります（11章）
- 目が顔の横にあり、ほとんど一周（330度ほど）見えます。真後ろは見えないので、後ろから近づくときは声をかけます
- いつも同じ流れ（時刻・手順）を好みます。急な音や動き、乱暴な扱いは、乳の出を悪くします（8章）
- 1日に 10〜14時間、横になって休みます。よく休める牛ほど、乳もよく出します（12章）

## まとめ

- 日本の乳牛のほとんどはホルスタイン。体重 600〜700 kg、1年に 8,000〜10,000 kg の乳を出す
- 乳を出すのはお産のあとだけ。「お産 → 乳 → 乾乳」をくり返す
- 13〜15か月で初めて授精し、22〜24か月で初めてのお産。5〜6歳で牧場を離れることが多い
- 牛は反芻動物で、群れで暮らし、暑さに弱い
