# 11. お産の前後の病気・蹄・暑さ

## この章でわかること

- お産の前後に病気が多いわけ
- 周産期の主な病気
- 蹄と脚の病気
- 暑熱ストレス
- そのほかの病気と、早く見つけるサイン

## お産の前後が危ない

- お産の 3週間前から 3週間後までを、**移行期**（transition period）または周産期と呼びます
- 乳を作り始めるのに、大量の**エネルギー**と**カルシウム**が必要になります。ところが、お産の前後は食べる量が減るので、足りなくなります
- 病気の多くがこの時期に起き、1つの病気が次の病気を呼びます（例: 乳熱 → 胎盤停滞 → 子宮炎、ケトーシス → 第四胃変位）

![お産の前後のエネルギーの不足](images/transition.svg)

## 周産期の主な病気

| 病気 | 英語 | 何が起きるか | サイン |
| --- | --- | --- | --- |
| 乳熱（低カルシウム血症） | milk fever（hypocalcemia） | 初乳を作るためにカルシウムが一気に使われ、血液のカルシウムが足りなくなる。お産から 3日以内に多い | 立てない、耳が冷たい、首を横に曲げてぼんやりする。「熱」と書くが、体温はむしろ下がる |
| ケトーシス | ketosis | エネルギー不足で体の脂肪を使いすぎ、ケトン体が増える | 食欲（特に濃厚飼料）がない、乳が減る、息や乳が甘ずっぱいにおい、やせる |
| 第四胃変位 | displaced abomasum（DA） | 第四胃にガスがたまってふくらみ、正しい位置からずれる（多くは左へ） | 食欲が落ち、乳が減る。お腹をたたくと「キーン」と金属のような音がする。手術が必要なことが多い |
| 胎盤停滞 | retained placenta | お産のあと 12〜24時間たっても、胎盤（後産）が出ない | 陰部から胎盤がぶら下がる。子宮炎の原因 |
| 子宮炎 | metritis | 子宮に細菌が入って炎症が起きる | くさいおりもの、熱。次の妊娠が遅れる |
| 脂肪肝 | fatty liver | 体の脂肪が肝臓にたまる | ケトーシスと一緒に起きやすい |

### 防ぐポイント

- 乾乳期に**太らせすぎない**（ボディコンディションスコア BCS で 3.0〜3.5）
- 乾乳期のエサで、カルシウムとカリウムを取りすぎない（アルファルファを乾乳牛に多く与えない, 6章）。陰イオン塩でカルシウムの仕組みを助けることもある
- お産の前後に**食べる量を落とさない**（エサを急に変えない、快適な分娩房）
- お産のあとに、体温・食欲・乳の量・ケトン体（乳や血液の簡単な検査）を確かめる

## 蹄と脚の病気

- **跛行**（はこう, lameness）: 脚をひきずったり、かばったりして歩くこと。乳牛にとても多い問題です
- 痛みで食べる時間と寝る時間が減り、乳が減り、発情も弱くなります

| 病気 | 英語 | 説明 |
| --- | --- | --- |
| 蹄底潰瘍 | sole ulcer | 蹄の底に傷ができる。アシドーシス、固い床、長く立っていることが原因 |
| 白帯病 | white line disease | 蹄の壁と底のつなぎ目が割れて、菌が入る |
| 趾皮膚炎（DD） | digital dermatitis | 蹄の後ろの皮膚に、イチゴのような赤いただれができる。菌でうつる。ふんで汚れた湿った床で広がる |
| 趾間腐爛 | foot rot | 蹄の間が腫れて、くさいにおいがする |

- 予防: **削蹄**（さくてい: 年に 2回ほど蹄を切って形を整える）、蹄浴（消毒液に蹄をひたす）、乾いた清潔な床、よく寝られる牛床、アシドーシスを防ぐエサ
- 歩き方に点数を付けて（ロコモーションスコア 1〜5）、早めに見つけます。カメラで自動で点数を付ける技術もあります

## 暑熱ストレス

- 牛は暑さに弱い動物です。第一胃の発酵と乳を作ることで、体の中でたくさん熱が出るためです
- 温度と湿度から計算する **THI**（温湿度指数）が 68〜72 を超えると、影響が出始めます

![気温と湿度から見る THI（暑熱ストレスの目安）](images/thi.svg)

| サイン | 説明 |
| --- | --- |
| 呼吸が速い | 1分に 60回以上。口を開けてハアハアする、よだれ |
| 立っている時間が増える | 体を冷やすため。蹄にも悪い |
| 水をたくさん飲む | |
| 食べる量と乳の量が減る | 乳脂肪も下がりやすい |
| 繁殖が悪くなる | 発情が弱くなり、受胎率が下がる |

対策は、送風（大きな扇風機）、細霧・散水（ミスト・シャワー）、日陰、屋根の断熱、換気、新鮮な水をたっぷり、涼しい時間に給餌、です。

## そのほかの病気

| 病気 | 英語 | 説明 |
| --- | --- | --- |
| 鼓脹症 | bloat | 第一胃にガスがたまり、左のお腹が大きくふくれる。マメ科の生草（アルファルファ・クローバー）で泡状のガスになることがある。息ができなくなり危険 |
| 創傷性第二胃炎 | hardware disease | 飲み込んだ針金や釘が第二胃に刺さる。磁石を飲ませて防ぐ |
| 伝染病 | infectious diseases | 口蹄疫、牛ウイルス性下痢（BVD）、牛伝染性リンパ腫（牛白血病）、ヨーネ病など。法律で届け出が必要なものもある |

## 早く見つけるサイン

| サイン | 疑うこと |
| --- | --- |
| 食べる量・反芻が減る | ほとんどの病気のはじまり |
| 乳の量が急に減る | 乳房炎、ケトーシス、第四胃変位、熱 |
| 熱がある（39.5 ℃ 以上） | 乳房炎、子宮炎、肺炎 |
| 寝てばかり、または立ってばかり | 跛行、乳熱、暑さ |
| 活動量が増える | 発情（病気ではない） |

「いつもとちがう」に早く気づくことが大事です。センサーは、これを毎日・1頭ずつ・24時間、数字で見ます（12章）。

## まとめ

- お産の前後3週間（移行期）は、エネルギーとカルシウムが足りなくなり、病気が多い
- 乳熱・ケトーシス・第四胃変位・胎盤停滞・子宮炎は、つながって起きやすい
- 跛行は乳牛に多い。削蹄・清潔な床・よく寝られる牛床で防ぐ
- 牛は暑さに弱い。THI 68〜72 を超えたら、送風・ミスト・水
- 食べる量・反芻・乳の量・体温の「いつもとちがう」が、早く見つけるサイン
