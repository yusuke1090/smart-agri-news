# 0. この教科書の使い方

## この章でわかること

- この教科書で学べること
- 読む順番
- 日本語と英語の切り替え方

## この教科書について

乳牛（おもにホルスタイン）について、からだ・繁殖・エサ・乳・病気・牧場の仕事を、ひととおりまとめた教科書です。
スマート農業News のニュースに出てくる言葉がわかること、センサーで牛を見るときに「何を測れば何がわかるか」を考えられることを目指しています。

| 部 | 内容 |
| --- | --- |
| 第1部 牛のからだ | 乳牛とは、4つの胃と反芻 |
| 第2部 繁殖と子牛 | 発情・授精・妊娠、1年1産、子牛の育て方 |
| 第3部 エサ | 粗飼料と濃厚飼料、配合飼料、チモシーとアルファルファ、サイレージ |
| 第4部 乳と病気 | 乳ができるしくみ、搾乳、乳房炎、血乳、お産の前後の病気 |
| 第5部 牧場とスマート酪農 | 牛の一日、牛舎、センサーとロボットでわかること |
| 付録 | 用語集（日本語・英語）、数字の目安 |

## 読む順番

| 人 | 読む順番 |
| --- | --- |
| はじめての人 | 1 → 2 → 3 → 5 → 8 → 9 章。そのあとは好きな章を |
| 病気のことを知りたい | 8 → 9 → 10 → 11 章 |
| エサのことを知りたい | 2 → 5 → 6 → 7 章 |
| センサーや IoT に関わる人 | 2 → 3 → 11 → 12 章と、付録B |
| 英語のニュースを読みたい | 付録A の用語集と、英語版の各章 |

## 日本語と英語を切り替える

- 上の **日本語 / English** を押すと、同じ章の同じ見出しの所が、もう一方の言葉で出ます
- 英語版は、やさしい英語で書いています。海外のニュースを読む練習にも使えます
- 英語の単語や文を選ぶと「🔤 訳す」が出て、日本語の意味がわかります（右下の「🔤 訳す」からも使えます）
- 英語版では、大事な言葉の後ろに日本語を付けています（例: mastitis（乳房炎））

## 画面の使い方

| 操作 | 動き |
| --- | --- |
| 上の章の名前を押す | 目次が開く。部ごとに並んでいて、今の章の見出しにも飛べる |
| ◀ ▶ | 前の章・次の章へ |
| 左上の「スマート農業News」 | ニュースに戻る |

- 開き直すと、前に読んでいた章の、読んでいた所から出ます
- アドレスの後ろに `#ch=9` のように章の番号が付きます。コピーすれば、その章を人に送れます

## 注意

> 数字は、日本のホルスタインのおおよその**目安**です。牛・牧場・季節・調べ方で変わります。
> 病気の説明は、しくみを知るためのものです。**治療は獣医師が決めます。** おかしいと思ったら、早めに獣医師に相談します。

## まとめ

- 乳牛のからだ・繁殖・エサ・乳・病気・牧場を、5つの部と付録でまとめている
- 日本語 / English で、同じ所を切り替えて読める。英文は「🔤 訳す」で意味がわかる
- 数字は目安。病気の治療は獣医師が決める
