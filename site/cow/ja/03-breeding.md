# 3. 繁殖と1年1産

## この章でわかること

- 乳を出すのに、お産が必要なわけ
- 1年1産とは、なぜ大事か
- 発情と、発情のサイン
- 人工授精・妊娠・分娩
- 繁殖の成績を表す数字

## 乳を出すにはお産が必要

- 牛は、子牛を産むと乳を出し始めます（泌乳, lactation）
- 乳の量は、お産から **6〜8週ごろにいちばん多くなり**（ピーク）、そのあと少しずつ減ります。この変化をグラフにしたものを泌乳曲線（lactation curve）といいます
- 減ってきたら、次のお産の 2か月ほど前に搾乳をやめて休ませます（**乾乳**, dry-off）。乳房を休ませ、次のお産と乳に備えます
- だから乳を出し続けるには、**毎年のようにお産**をさせる必要があります

## 1年1産

![1年1産のカレンダー](images/one-calf-a-year.svg)

- **1年1産**: 1頭の牛が、1年に1回お産をすること。お産からお産までの日数（**分娩間隔**, calving interval）を 365日にするのが目標です
- 妊娠期間は約 **280日** です。365 − 280 = 85 なので、**お産から 85日以内に、次の子を妊娠させる**必要があります
- お産のあと、子宮が元に戻るまで 40日ほどかかります。そのため、お産から 50〜60日は授精しません（自発的待機期間, VWP）
- 授精できるのは 60〜85日目ごろ。発情は 21日ごとなので、チャンスは 1〜2回しかありません
- 1回の授精で妊娠するのは 3〜4割ほどです。だから 1年1産は、実際にはかなり難しく、日本の平均の分娩間隔は 400日を超えています

### 分娩間隔が長いと困ること

| 困ること | 理由 |
| --- | --- |
| 乳が減る | ピークを過ぎた、乳の少ない期間が長くなる |
| 生まれる子牛が減る | 後継ぎの乳牛や、売る子牛が減る |
| 病気が増える | 泌乳の後半に太りすぎ、次のお産で病気になりやすい（11章） |

## 発情

- **発情**（はつじょう, estrus / heat）: メスが交配を受け入れる状態
- 約 **21日**（18〜24日）ごとに来ます（発情周期）
- 発情が続くのは **10〜18時間ほど**と短いです。乳をたくさん出す牛ほど、短く弱くなりがちです
- 排卵は、発情が終わってから 10〜12時間ほどあとです
- 夜に始まることも多く、見逃しやすいです

![首輪で見た1日の歩数と発情（21日ごとに増える）](images/heat-activity.svg)

### 発情のサイン

| サイン | 英語 | 説明 |
| --- | --- | --- |
| 乗られてもじっとしている | standing heat | いちばん確かなサイン。ほかの牛に乗られても逃げない |
| ほかの牛に乗る | mounting | 発情の牛や、発情の近い牛が乗る |
| よく歩く・動く | increased activity | 歩数がふだんの 2〜4倍になる。首輪や歩数計で見つける |
| 落ち着かない・よく鳴く | restlessness | |
| 透明な粘液 | clear mucus | 陰部から糸を引く透明な粘液が出る |
| 陰部が腫れる・赤い | swollen vulva | |
| 食べる量・乳の量が少し減る | | |
| 尾の付け根の毛が乱れる | | 乗られてこすれる。尾の付け根に塗料やシールを付けて確かめる方法もある |

- 来た発情のうち、見つけられた割合を**発情発見率**といいます。人の目だけでは半分ほどしか見つけられないこともあり、センサーが役立ちます（12章）

## 人工授精

- 日本の乳牛は、ほとんどが**人工授精**（AI, artificial insemination）で妊娠します。獣医師や家畜人工授精師が、凍らせた精液（ストロー）を子宮に入れます
- 授精のタイミングは、発情が始まってから 12〜18時間後がよいとされます。「朝に発情を見つけたら夕方に、夕方に見つけたら次の朝に授精する」という目安があります（AM-PM ルール）
- 精液は、乳の量・体型・病気への強さなどの能力がわかっている父牛（種雄牛）から選びます。遺伝子で能力を予測する方法（ゲノム評価）も使われています
- **性選別精液**（sexed semen）: メスが生まれる確率を 9割ほどにした精液。後継ぎの乳牛を確実に得たいときに使います
- ホルモン剤で排卵の時期をそろえ、決まった日に授精する方法もあります（定時人工授精。オブシンクなど）

## 妊娠と分娩

- 妊娠期間は約 **280日**（275〜285日）です
- **妊娠鑑定**（pregnancy diagnosis）: 授精から 30〜40日ごろに、獣医師が直腸からの触診や超音波（エコー）で確かめます
- 授精から 21日後ごろにまた発情が来たら、妊娠していません（再発情）
- **分娩**（ぶんべん, calving）が近づくと、乳房が張る、尾の付け根のまわりがゆるむ、体温が 0.5 ℃ ほど下がる、落ち着かなくなる、などのサインがあります。センサーで知らせる方法もあります（12章）
- お産のあと 12〜24時間以内に、胎盤（後産）が出ます。出ないのが胎盤停滞です（11章）

## 繁殖の成績を表す数字

| 数字 | 英語 | 意味 | 目標の目安 |
| --- | --- | --- | --- |
| 分娩間隔 | calving interval | お産からお産までの日数 | 365〜400日（短いほどよい） |
| 空胎日数 | days open | お産から妊娠までの日数 | 85〜115日 |
| 初回授精日数 | days to first service | お産から最初の授精までの日数 | 60〜80日 |
| 受胎率 | conception rate | 授精したうち、妊娠した割合 | 40% 以上 |
| 発情発見率 | heat detection rate | 来た発情のうち、見つけた割合 | 60〜70% 以上 |
| 妊娠率 | pregnancy rate | 21日ごとに、妊娠できる牛のうち妊娠した割合（発情発見率 × 受胎率） | 20% 以上 |
| 初産月齢 | age at first calving | 初めてのお産の月齢 | 22〜24か月 |

## まとめ

- 乳はお産のあとに出る。ピークはお産から 6〜8週。次のお産の 2か月ほど前に乾乳する
- 1年1産 = 分娩間隔 365日。妊娠期間が 280日なので、お産から 85日以内に妊娠させる
- 発情は 21日ごと、10〜18時間と短い。見逃さないことが大事で、センサーが役立つ
- ほとんどが人工授精。発情が始まって 12〜18時間後に授精する
