# 9. 乳房炎（大腸菌による乳房炎）

## この章でわかること

- 乳房炎とは
- 臨床型と潜在性
- 原因になる菌（伝染性と環境性）
- 大腸菌で乳房炎になるしくみ
- 見つけ方とセンサー

## 乳房炎とは

- **乳房炎**（にゅうぼうえん, mastitis）: 乳房の中（乳腺）の炎症です。ほとんどは、**乳頭口から細菌が入って**起きます
- 乳牛の病気でいちばん多く、損もいちばん大きい病気です。乳が減る、乳を捨てる、治療費がかかる、牛を手放す、乳の値段が下がる（体細胞数）、などの損が出ます
- 乳腺の中は、栄養たっぷりの乳で満たされ、温度は 38 ℃ ほどです。細菌にとって、とても増えやすい場所です

## 臨床型と潜在性

| 種類 | 英語 | 見た目 | 見つけ方 |
| --- | --- | --- | --- |
| 臨床型乳房炎 | clinical mastitis | 乳にブツ（固まり）が出る、水っぽい、色が変。乳房が腫れる・熱い・痛がる。重いと熱が出て食べない | 前搾りで乳を見る、乳房をさわる |
| 潜在性乳房炎 | subclinical mastitis | 乳も乳房もふつうに見える | 体細胞数（SCC）、PL テスト（CMT）、電気伝導度 |

- 潜在性乳房炎は、臨床型の 15〜40倍あるといわれます。気づかないまま乳が減り、ほかの牛にうつることもあります
- 臨床型の重さは、軽症（乳の異常だけ）・中等症（乳房の腫れもある）・重症（熱・食欲がない・立てないなど、全身の症状）に分けます

### PL テスト（CMT）

![PL テスト（CMT）の見方](images/cmt.svg)

- 4つのくぼみのある板（パドル）に、分房ごとに乳を少し搾り、試薬と混ぜます
- 体細胞が多いと、混ぜた液がドロッとしたゲルになります。固まり方で、程度がわかります
- 牧場ですぐにできる検査です。英語では CMT（California Mastitis Test）といいます

## 原因になる菌

![伝染性と環境性の乳房炎のうつり方](images/mastitis-routes.svg)

| グループ | 菌の例 | どこにいる | どううつる |
| --- | --- | --- | --- |
| 伝染性 | 黄色ブドウ球菌（Staphylococcus aureus）、無乳性レンサ球菌（Streptococcus agalactiae）、マイコプラズマ（Mycoplasma） | 感染した乳房の中、乳頭の傷 | 搾乳のときに、ミルカー・手・タオルを通して、牛から牛へ |
| 環境性 | 大腸菌（Escherichia coli）、クレブシエラ（Klebsiella）、環境性レンサ球菌（Streptococcus uberis など） | ふん・敷料・泥・汚れた水 | 牛が寝たり歩いたりしたときに、乳頭の先が汚れて |

- **伝染性の菌**は、長引きやすく治りにくいです。黄色ブドウ球菌は抗生物質が効きにくいことが多く、マイコプラズマは抗生物質がほとんど効かず、群れに広がります。搾乳の衛生と、感染した牛を分けることで防ぎます
- **環境性の菌**は、牛舎の衛生（敷料・ふん）がカギです。大腸菌は、急に重くなることがあります

## 大腸菌で乳房炎になるしくみ

![大腸菌で乳房炎になるまで](images/ecoli-mastitis.svg)

### 1. 大腸菌はどこにいるか

- 大腸菌（だいちょうきん, E. coli）は、牛の腸にふつうにいる菌で、**ふんに大量に含まれます**
- ふんが混じった敷料（おがくず・わら・戻し堆肥など）、ぬかるみ、汚れた水の中で増えます。**暑くて湿っている**と、特に増えます

### 2. どうやって乳房に入るか

- 牛は 1日に 10〜14時間横になります。寝ると、乳頭の先が敷料にふれます
- **搾乳の直後は乳頭口が開いています**（閉じるまで 30分〜1時間ほど）。このときに汚れた所に寝ると、菌が入りやすくなります
- 乳頭の先が傷ついていたり、ガサガサだったりすると（過搾乳など）、入りやすくなります
- **乾乳期のはじめと、お産の前後**も入りやすい時期です（乳頭口の栓ができる前と、なくなったあと）

### 3. 体の中で何が起きるか

1. 入った大腸菌は、乳の中で速く増える
2. 牛の体は菌を退治するために、血液から白血球（好中球）を乳房に大量に送る → **体細胞数が急に増える**
3. 退治されて壊れた大腸菌から、**エンドトキシン**（内毒素, endotoxin）という毒が出る
4. エンドトキシンが強い炎症を起こし、血液に入ると、**全身の症状**になる

### 4. どんな症状になるか

- **乳房**: 急に腫れて、熱く、固くなる
- **乳**: 水っぽい・黄色っぽい（黄色い水のよう）、ブツが出る。乳の量がガクッと減る
- **全身**: 熱が出る（40 ℃ 以上）、震える、食べない、反芻が止まる、下痢、脱水。重いと立てなくなり、ショックで死ぬこともある（甚急性乳房炎）。熱がむしろ下がってくるのは、ショックの危ないサイン
- 重くなるかどうかは、菌の量よりも**牛の免疫の状態**で決まります。お産の直後は免疫が弱く、重くなりやすいです
- 一方で、牛の免疫が早く菌を退治できたときは、軽いまま数日で治ることも多いです

### 5. 治療

- **すぐに獣医師に連絡します。** 重い大腸菌性乳房炎は、時間との勝負です
- 獣医師が行う治療の例: 点滴（輸液）で脱水とショックを防ぐ、炎症を抑える薬、抗生物質、カルシウム
- 毒素と菌を含む乳を出すために、こまめに搾ることもあります（頻回搾乳）
- 抗生物質を使ったら、休薬期間が終わるまで、乳は出荷しません（8章）

### 6. 予防

| すること | なぜ |
| --- | --- |
| 敷料を乾いた清潔な状態に保つ。ふんはこまめに取り、敷料を足す・替える | 大腸菌は、湿ったふんと敷料で増える |
| 搾乳の後に、ポストディッピングをする | 乳頭口が閉じるまで、菌を防ぐ |
| 搾乳の後に新しいエサを与え、30分〜1時間は立っていてもらう | 乳頭口が閉じる前に寝ないように |
| 前処理で乳頭をきれいにし、乾かしてからミルカーを付ける | 汚れや水と一緒に菌が入らないように |
| 暑さ対策（送風・換気） | 暑いと菌が増え、牛も弱る |
| お産の場所（分娩房）を清潔にする | お産の前後は、特にかかりやすい |
| 乾乳のときに乳頭口をふさぐ（乳頭シーラント） | 乾乳中に菌を入れない |
| ワクチン | 国によっては、大腸菌（J5）のワクチンで重くなるのを防ぐ |

## 見つけ方とセンサー

| 方法 | わかること |
| --- | --- |
| 前搾りで乳を見る | 臨床型（ブツ・水っぽい・血） |
| PL テスト（CMT） | 分房ごとの体細胞の多さ |
| 牛群検定の体細胞数 | 1頭ごとの潜在性乳房炎 |
| 電気伝導度（搾乳ロボット・ミルクメーター） | 乳房炎の乳は塩分（ナトリウム・塩素）が増えて、電気を通しやすくなる |
| 乳量の急な減少、反芻・活動量・体温 | 全身の症状が出る、重い乳房炎 |

## まとめ

- 乳房炎は、乳頭口から細菌が入って起きる乳腺の炎症。乳牛でいちばん多く、損も大きい
- 見てわかる臨床型と、見えない潜在性がある。潜在性は体細胞数や PL テストで見つける
- 菌は、牛から牛へうつる**伝染性**（黄色ブドウ球菌など）と、ふんや敷料からの**環境性**（大腸菌など）
- 大腸菌は、ふんで汚れた湿った敷料 → 搾乳直後の開いた乳頭口 → 乳の中で増える → 壊れてエンドトキシン → 全身の症状
- 乾いた清潔な敷料、ポストディッピング、搾乳後に寝かせない、で防ぐ。重いときはすぐ獣医師へ
