📝 伝言板

将来やりたいこと・アイデア・相談を書き込む場所です。誰でも読めます。書き込みと編集には GitHub のアカウント（無料）が必要です。

「やりたいこと」「アイデア」には、似たことをしている会社や製品を調べた結果（🔎 関連する事業）を付けています。

＋ 書き込む GitHub で一覧を見る

書いた内容は誰でも見られます。個人情報は書かないでください。フォームから書いたものは自分では直せないので、直したいときはコメントで書き足してください。

書き込み方・編集のしかた
  1. 「＋ 書き込む（アカウント不要）」を押すと、このページの中に書き込み欄が出ます。合言葉（サイトの持ち主から聞いてください）を入れて「送る」と、少しして伝言板に出ます
  2. GitHub のアカウントがあれば「＋ 書き込む」から GitHub の書き込み画面でも書けます。題名・種類・内容を書いて「Create」を押すと、この伝言板に出ます
  3. GitHub で書いたものは、各書き込みの「編集・コメントする」から GitHub を開き、本文右上の「…」→「Edit」で直せます
  4. コメントは、各書き込みの「💬 コメント」でこのページの中で読めます。合言葉があれば、ここからコメントも書けます
  5. 終わった・取り下げたいときは、GitHub で「Close」を押すと、伝言板から消えます

読み込み中…

書き込みは GitHub の Issues（ラベル「伝言板」）に保存され、このページはそれを表示しています。アカウントなしのフォームから書いたものは、サイトの持ち主のアカウントで保存され、書いた人の名前は本文に入ります。書き込んだ内容は誰でも見られるので、個人情報は書かないでください。

「🔎 関連する事業」は、Claude（AI）がウェブで調べてまとめたものです。調べた日の時点の内容で、まちがいや古い情報を含むことがあります。出典のページで確かめてください。
