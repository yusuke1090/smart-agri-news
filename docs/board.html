📝 伝言板

将来やりたいこと・アイデア・相談を書き込む場所です。誰でも読めます。書き込みと編集には GitHub のアカウント（無料）が必要です。

＋ 書き込む GitHub で一覧を見る
書き込み方・編集のしかた
  1. 「＋ 書き込む」を押すと GitHub の書き込み画面が開きます（初めてのときはログイン・アカウント作成）
  2. 題名・種類・内容を書いて「Create」を押すと、この伝言板に出ます
  3. 直したいときは、各書き込みの「編集・コメント」から GitHub を開き、本文右上の「…」→「Edit」で直せます。自分の書き込みは自分で直せます
  4. コメントは、各書き込みの「💬 コメントを見る」でこのページの中で読めます。コメントを書くときは「＋ コメントを書く」から GitHub を開きます
  5. 終わった・取り下げたいときは「Close」を押すと、伝言板から消えます

読み込み中…

書き込みは GitHub の Issues（ラベル「伝言板」）に保存され、このページはそれを表示しています。書き込んだ内容は誰でも見られるので、個人情報は書かないでください。
